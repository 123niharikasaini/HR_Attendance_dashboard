# HR Attendance Dashboard

### Project Overview

This project presents an Employee Attendance Analysis Dashboard built in Power BI using Atliq company data from the Codebasics platform. The dashboard focuses on analyzing employee presence patterns, leave behavior, and work-from-home (WFH) trends over time.

The objective is to help HR teams understand workforce behavior, identify patterns in attendance, and support better planning for operations and employee engagement.

### Purpose

Organizations need visibility into employee attendance trends to manage productivity, workforce planning, and hybrid work policies effectively.

This dashboard provides insights into employee presence, leave usage, and WFH preferences, enabling HR teams to make informed decisions around scheduling, resource allocation, and event planning.

### Tools & Technologies

1. Power BI Desktop
2. Power Query
3. DAX (Data Analysis Expressions)
4. Data Modeling
5. Data Visualization & KPI Monitoring

### Data Source
The dataset is sourced from Codebasics and contains employee attendance records from April 2022 to June 2022.

It captures daily attendance behavior across employees and contains attendance status indicators.

### Key Performance Indicators (KPIs)

The dashboard tracks key workforce metrics including:

1. Presence % – Percentage of days employees were present
2. Work From Home (WFH) % – Percentage of days employees worked remotely
3. Sick Leave % – Percentage of sick leave taken
4. Total Working Days – Total number of working days in the selected period

### Dashboard Components

##### Attendance Overview
1. Employee-level KPI table showing presence, WFH, and leave percentages
2. Attendance matrix displaying daily records for each employee
##### Trend Analysis
  Area charts showing trends in presence %, WFH %, and sick leave % over time
##### Weekly Attendance Patterns
  Highlights day-wise variations in presence, WFH, and leave trends to identify employee preferences

### Key Insights
1. Observed an increase in WFH adoption (~11%) and sick leave (~2%) over time.
2. Identified weekday trends, with highest WFH preference on Fridays (~16%).
3. Noted consistent presence levels despite rising WFH, indicating a shift toward hybrid work patterns.

### Conclusion

The dashboard provides a clear view of employee attendance behavior and evolving work preferences. It empowers HR teams to make data-driven decisions, optimize hybrid work strategies, and improve overall workforce management.
